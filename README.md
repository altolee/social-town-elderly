# 社福小鎮｜王伯伯篇

獨居老人社會福利服務七階段像素風互動情境遊戲。

## 使用

這是純靜態網站，直接開啟根目錄的 `index.html` 即可操作。
部署至 Vercel 時，選擇 Framework Preset: Other；Root Directory: `./`；不需設定 Build Command。

## 操作

空白鍵／右方向鍵：下一步；左方向鍵：上一步；1、2、3：切換視角；M：音樂開關。
